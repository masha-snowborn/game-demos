# Game demos

Playable browser prototypes: Dish Happens and Pills & Thrills.

Open `index.html` to choose a game. All runtime artwork, fonts, code and audio are included. Only attribution links lead to external websites. The games use virtual credits.

## Загрузка на GitHub

1. Распакуйте `game-demos.zip`.
2. Откройте папку `game-demos`.
3. В репозитории нажмите **Add file → Upload files**.
4. Перетащите **содержимое папки**: `index.html`, `README.md`, папки `dish-happens` и `pills-and-thrills`. Не загружайте сам ZIP и не помещайте всё внутрь дополнительной папки `game-demos` в репозитории.
5. Нажмите **Commit changes**.

В корне репозитория должны оказаться `index.html`, `dish-happens/` и `pills-and-thrills/`. Файл `.nojekyll` можно добавить отдельно, если Finder его скрывает; для этой структуры он необязателен.

Этот комплект сам по себе ничего не публикует и не меняет видимость репозитория. Доступ и размещение сайта настраиваются отдельно. Private-репозиторий сам по себе не делает опубликованный GitHub Pages сайт закрытым.
